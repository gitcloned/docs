Every project can have a default dashboard. The default dashboard is possible because there is a very clear intent of every project

 - Basic call stats metric
	 - How many calls
	 - How many agents
	 - Distribution across disposition
- Rubrics and their stats
	- Distribution across diff type of rubric
- Grid
	- To filter any call basis the basic metrics or rubric and deep-dive

The UI can have 2 views, with common filter as date range
 - Analytics (Report widgets as described above)
 - Data (Grid view)

Both view should show Conversion rate as well, which filters basis the filter applied in view

Conversion rate is always, call to meeting booked
